## Finished: TraceChain ("מדרישה לקוד")
40 s, 1920×1080, 30 fps. Follows the tag `[SRS-042]` from requirement → spec.md → clarify → plan.md → tasks.md → test + commit → grep chain.
- All text, code, colors and timings: `src/props.ts` (zod schema, editable in Studio).
- Derived frame timeline: `src/timeline.ts`. Scenes: `src/scenes/Scenes.tsx`, one `<Sequence>` per scene.
- Components: TypeWriter, EditorWindow, Terminal, Chip, ChainPill, TagPulse, SrsCard, Workspace (camera pan), FlyingChips, TerminalLayer, Chain, Header, Background, Sound.
- Two outputs: `npm run render:sound` and `npm run render:silent` (props `sound: false`).
- Commands: `npm ci --ignore-scripts`, `npm run studio`.

## Decisions to keep
- **Dependency safety (user asked for it):** pin exact versions published ≥ 2 weeks ago, check publisher and repo, run `npm audit` and `npm audit signatures`, install with `--ignore-scripts`. Remotion is pinned to 4.0.534 (4.0.538 was only 1 day old when checked). zod 4.5.4, react 19.3.0, typescript 7.0.2.
- **Fonts are local** (`public/fonts`, loaded with `@remotion/fonts`, with `SHA256SUMS`) instead of `@remotion/google-fonts`: the cloud renderer could not fetch Google Fonts. Keeps renders offline and reproducible.
- Hebrew: explicit `direction: 'rtl'`; code, terminal and chat `ltr`. Wrap Latin and number runs inside Hebrew in `<bdi dir="ltr">` (otherwise "1 kHz" shows as "kHz 1").
- Motion: `spring({damping: 200})` for entrances and camera; linear `interpolate` for typing.
- Quality: PNG frames, H.264 CRF 14, bt709, `CameraMotionBlur` only while the camera moves.
- Sound effects are generated by `scripts/make-sfx.mjs` (no downloads).
- `remotion.config.ts` points at a cloud-only browser path but only if it exists, so it is harmless locally.
